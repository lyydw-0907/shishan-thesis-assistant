# 支持范围与已知限制

## 文件与兼容性

支持普通 Transitional OOXML `.docx`，上传大小上限 20 MB；解压成员不超过 5000 个，声明的总解压大小不超过 100 MB。不支持 `.doc`、PDF、加密文档及 Strict OOXML。损坏文档、含 DTD/实体声明的 XML 会拒绝处理。复杂第三方生成文档可能出现未覆盖结构。

## 各项检查边界

| 项目 | 当前范围 | 仍需核对 |
| --- | --- | --- |
| 文字与标题 | 正文顶层段落、样式继承及人工角色指定 | 自动分类可能有误；不保证覆盖所有表格、文本框、修订及域结果 |
| 多级列表 | 直接设置、样式继承、层级覆盖及受控字号修改 | 不模拟最终显示编号；共享定义冲突、编号模板及重新开始语义需核对 |
| 字数 | 中文按字计，英文及数字按连续词估算；含表格，可选文本框和脚注/尾注 | 不承诺与 Word 一致；正文范围依赖章节识别；不统计公式对象、页眉页脚及批注 |
| 参考文献 | 按段落识别条目；常见数字和作者—年份引用匹配 | 续行、机构作者、同名同年、复杂姓名或非常规写法可能误判；不核验文献真实性 |
| 图表题注 | 普通段落、表格单元格及部分同列成组布局 | 浮动对象、合并单元格、复杂布局与实际跨页需核对；不自动移动或重排编号 |
| 图表引用 | 正文顶层文字，支持范围及省略写法 | 表格、脚注、文本框和自动交叉引用域不保证覆盖；未识别不等于确实未引用 |
| 页码 | 按节解析有效页眉页脚引用、继承、编号格式和起始设置 | 不计算实际页数，不自动判断该学院对各节的要求；首页或偶数页留空可能是有意设置 |
| 镜像边距 | 可确认切换现有 settings.xml 中的开关 | 保留边距数值和装订线；缺少 settings.xml 时不自动补造；左右页效果需检查 |
| 页眉页脚设计 | 按选定节号确认替换普通页内容，按选项处理首页 | 后续链接到该节的内容可能继承；不新增正文分节，不把首页留空等同于正文从1开始 |
| 公式 | 统计 Word 公式对象并保留结构 | 无法可靠判断每个变量斜体、函数/单位正体及图片公式内容 |

## 修改与视觉结果

每次修改须经预览及用户确认，仅处理勾选项目，输出副本而不覆盖原文件。校验文字、表格、图片、公式等受保护结构及未修改部件；校验失败会中止生成。结构保留校验不等于视觉排版完全不变，字号、边距或页眉页脚变化可能改变分页。

下载后在 Word 更新域，检查目录页码、标题落在页尾、图表跨页、公式和奇偶页效果。规则通过与内容保留通过均不替代学校审查。
